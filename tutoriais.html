Primeiros Passos com Arduino

Neste tutorial, você aprenderá a fazer um LED piscar usando o Arduino. Este é o primeiro passo para entender o básico de eletrônica e programação no ambiente Arduino. Seguindo este simples projeto, você terá a oportunidade de aprender como interagir com o hardware, programar o Arduino e controlar um componente externo, como o LED.

Materiais necessários:

1 Arduino (qualquer modelo, como o Uno ou Nano) 1 LED 1 Resistor de 220Ω Fios de conexão (jumpers) Protoboard (opcional) Passo 1: Conectando o LED ao Arduino Insira o LED na protoboard (se estiver usando uma). Conecte o pino positivo do LED (geralmente o maior) ao pino digital 13 do Arduino. Conecte o pino negativo do LED ao resistor de 220Ω. Conecte a outra extremidade do resistor ao pino GND (terra) do Arduino.

Passo 2: Programando o Arduino

Agora, você vai programar o Arduino para fazer o LED piscar. Aqui está o código simples: void setup() { pinMode(13, OUTPUT); // Configura o pino 13 como saída } void loop() { digitalWrite(13, HIGH); // Acende o LED delay(1000); // Aguarda 1 segundo digitalWrite(13, LOW); // Apaga o LED delay(1000); // Aguarda 1 segundo }

Passo 3: Carregando o Código no Arduino

Abra o Arduino IDE no seu computador. Selecione a placa e a porta correta no menu "Ferramentas". Clique no botão de upload (seta para a direita) para enviar o código para o seu Arduino.

Passo 4: Testando o LED

Após carregar o código, o LED deve começar a piscar com um intervalo de 1 segundo.
